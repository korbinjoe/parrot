# Parrot 0.1.4

This release makes the everyday translation workspace easier to click and edit,
and refreshes the app icon with a white tile and a restrained blue parrot.

## Changes

- Click the full menu, sidebar, history or learning row. Expand or collapse an
  engine section anywhere along its heading; common icon buttons use 32 pt
  hit targets.
- Edit captured or typed source text and translate again in the same window.
  Use one preferred engine with an automatic backup by default, or compare
  additional engines from the result menu or translation settings.
- Configure enabled engines, model order, credentials and validation with
  clearer draft, cancellation, reset and retry behavior.
- Improve selection capture, clipboard restoration, short-word language
  detection, result ordering, history refresh and Ollama TranslateGemma support.
- Preserve the fixes from 0.1.1–0.1.3 for settings responsiveness, hotkey
  modifier release and OpenCode Go sessions across translation retries.

## Validation

- All 268 Swift unit and integration tests passed.
- Release build and native GUI acceptance passed, including actual mouse clicks
  in sidebar/disclosure trailing space and workspace position/size stability.
- Application signature and both distribution formats verified; SHA-256
  checksums are included with the downloads.

## Install

macOS 13+, Apple silicon: download `Parrot-0.1.4-arm64.dmg` and drag Parrot to
Applications. `Parrot-0.1.4-arm64.zip` is also available. System Translation
requires macOS 15+ and the relevant language packs.

The app is ad-hoc signed, matching previous releases, and is not notarized.
If Gatekeeper blocks first launch, use System Settings → Privacy & Security →
Open Anyway. Allow Accessibility for selection capture and global shortcuts,
and Screen Recording for screenshot OCR when those features are needed.

`SHA256SUMS.txt` contains checksums for both downloads. Verify with:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## 更新内容

- 白底蓝鸟图标，在小尺寸下更清楚。
- 菜单、侧栏、历史和学习列表整行可点；折叠标题整行展开/收起，小图标按钮扩大点击范围。
- 原文编辑、重译和复制集中在同一工作区，默认首选引擎与备用引擎，按需对比更多译文。
- 改进服务配置、草稿保护、取消测试、错误恢复、划词捕获、语言识别与 Ollama 兼容性。
- 保留已发布版本的设置性能、快捷键修饰键等待和 OpenCode 会话修复。
