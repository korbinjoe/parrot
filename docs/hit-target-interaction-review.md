# 点击范围修正

目标：用户看到的菜单行、折叠标题和按钮留白都能直接操作，不需要瞄准文字或图标。
本次范围按用户反馈收窄到点击区域，不改翻译流程或配置逻辑。

## 交互检查

| 路径 | 问题 | 原因与修正 | 验收 |
| --- | --- | --- | --- |
| 设置 → 切换菜单 | P1：侧栏留白不响应 | 将整行矩形命中区放入 Button label | 点击侧栏最右侧空白后进入翻译设置 |
| 翻译设置 → 添加引擎 → 折叠/展开 | P1：默认操作只落在小箭头 | 整个标题行作为原生 Button，保留展开状态和内部控件独立性 | 点击标题右侧空白能连续展开、收起 |
| 菜单栏 → 操作或历史 | P1：已铺满的视觉行缺少完整点击区域 | 菜单行与最近记录完整矩形可点 | 实际打开菜单并检查整行操作 |
| 历史、复习、词库 → 选记录/答案 | P1：文字外的留白难点 | 把整行/卡片外观纳入 label 的命中区 | 保持选中、复用与独立操作按钮行为 |
| 工作区 → 菜单、复制、关闭、语言 | P1：小图标与装饰内边距不易点击 | 共享图标控件与工作区小操作使用 32 pt 矩形区域；紧凑设置操作至少 28 pt | 检查工作区排版、菜单与输入仍可用 |

## 实现边界

- 点击区域只扩展到控件自身的布局范围，不覆盖相邻控件。
- 不给包含输入框、开关、多个动作的父容器添加统一 tap gesture。
- 保留 Button/Menu 的键盘与辅助功能行为；折叠标题暴露展开/折叠状态。
- 只读徽标保持原样，视觉图标大小保持原来的紧凑尺度。
- 继续使用已确认的白底蓝鸟应用图标。
