# Proposal: Parrot — macOS 开源翻译与 OCR 工具（复刻 Bob 全部功能）

- **Change name**: `macos-translator-bob-clone`
- **Status**: Proposed
- **Author**: fullstack-engineer (drafted by Lead, dispatch infra unavailable)
- **Date**: 2026-06-15

## Summary

构建一款 macOS 原生开源翻译 + OCR 工具（暂名 **Parrot**），完整复刻商业软件 Bob（bobtranslate.com）的全部核心能力：划词翻译、截图 OCR 翻译、输入翻译、查单词、多翻译引擎聚合对比、可扩展插件系统（接入 GPT/Claude/Gemini/DeepSeek 等大模型）、历史记录与收藏夹、语音合成（TTS），以悬浮窗「即用即走」的非侵入式交互呈现。项目以开源协议发布，核心价值在于**可扩展的引擎/插件架构**与**完全免费、无次数限制**。

## Motivation

- Bob 是 macOS 上口碑极佳的效率工具，但**闭源**、Pro 功能买断收费、免费版有每日次数限额（翻译 15 次/OCR 10 次）。
- 社区已有大量 Bob 第三方插件（接入各类大模型翻译），说明**插件生态**是核心需求，但插件依附于闭源宿主，存在长期可维护性风险。
- 大模型翻译质量已显著超越传统机翻，用户需要一个**开源、可自由接入任意 LLM、无限制**的本地翻译工作流工具。
- 目标用户：程序员（读英文文档/Issues）、研究者（读论文）、内容创作者/译者、需高频处理多语言信息的知识工作者。

## Goals

1. **划词翻译**：全局快捷键触发，通过辅助功能（Accessibility）API 捕获当前选中文本，悬浮窗即时展示翻译。
2. **截图翻译 / OCR**：快捷键触发屏幕区域截图 → OCR 文字识别 → 翻译；支持图片/PDF 中不可复制文字。
3. **输入翻译**：快捷键唤起输入框，键入文本回车翻译。
4. **查单词**：对单词返回词典释义（音标、词性、例句）。
5. **多翻译引擎聚合**：内置 Apple、Google、DeepL、腾讯、百度、有道、彩云、Microsoft、OpenAI 等引擎，支持**同时开启多个引擎并排对比**（≥10 个）。
6. **插件系统**：定义统一插件协议，支持第三方/社区编写翻译插件接入任意 LLM（GPT/Claude/Gemini/DeepSeek 等），可热加载、可配置 API Key 与 Prompt。
7. **历史记录与收藏夹**：本地持久化翻译历史，支持收藏、检索。
8. **语音合成（TTS）**：朗读原文/译文，支持多语言。
9. **非侵入式交互**：悬浮窗即用即走、自动消失、不抢占注意力；支持菜单栏常驻、全局快捷键自定义。
10. **PopClip 集成**：支持选中文本后通过 PopClip 调起翻译。
11. **开源治理**：明确开源 License、贡献指南、插件开发文档。

## Non-goals

- **不支持非 macOS 平台**（Windows/Linux）。首版聚焦 macOS 原生体验；跨平台不在范围内（参见 design.md 的取舍论证）。Windows 用户可使用 STranslate 等开源替代。
- **不自建翻译/OCR 云服务**：复用系统能力（Apple Translation/Vision）与第三方 API，不训练自有模型。
- **不内置付费代理或破解的免费 LLM 接口**：仅提供官方 API 接入与用户自带 Key。
- **首版不做移动端、不做浏览器扩展**（沉浸式网页翻译另属范畴）。
- **不做账号体系/云同步**（首版纯本地；云同步列为未来可选项）。

## Approach（概要，详见 design.md）

- **技术栈**：Swift + SwiftUI（UI）+ AppKit（悬浮窗、全局事件、菜单栏等 SwiftUI 能力不足处）。推荐原生方案而非 Electron/Tauri 跨平台，理由：辅助功能 API、全局快捷键、截图、Vision OCR、菜单栏悬浮窗均深度依赖 macOS 原生能力，原生方案体验与性能最佳、安装包最小。
- **核心架构分层**：交互层（快捷键/截图/选词捕获）→ 应用服务层（翻译编排、引擎聚合、历史）→ 引擎抽象层（`TranslationProvider` 协议）→ 内置引擎 + 插件运行时。
- **OCR**：首选 Apple Vision 框架（离线、免费、系统级），插件可扩展第三方 OCR。
- **插件系统**：基于声明式 manifest + JS 运行时（对齐 Bob 现有插件生态，降低社区迁移成本）。
- **数据**：本地 SQLite/Core Data 存历史与收藏；Keychain 存 API Key。
- **分阶段交付**：MVP（划词+输入翻译+单引擎+悬浮窗）→ OCR → 多引擎聚合 → 插件系统 → TTS/收藏/PopClip。

## Risks

| 风险 | 影响 | 缓解 |
|------|------|------|
| 辅助功能权限获取选中文本不稳定（不同 App 行为不一） | 划词翻译失败 | 多策略回退：AX API → 模拟复制读剪贴板；明确权限引导 |
| 各翻译引擎 API 鉴权/计费/限流差异大 | 引擎不可用 | 引擎抽象层统一错误处理 + 降级；用户自带 Key |
| 插件运行 JS 存在安全风险（任意网络/代码执行） | 安全 | 沙箱化 JS 运行时、网络白名单、权限声明（详见 plugin spec） |
| App Store 上架对辅助功能/全局监听限制严格 | 分发受限 | 优先 GitHub Release + 公证(notarization) 直分发，App Store 为可选 |
| 复刻范围大，易范围蔓延 | 交付延期 | 严格 MVP 边界 + 里程碑门禁（见 tasks.md） |
| 闭源 Bob 插件协议无公开规范 | 兼容性 | 自定义协议为主，尽量贴近其插件结构，不承诺 100% 兼容 |
