OCR 优化

框选本身交给系统截图交互，Parrot 只设计增量价值：识别结果选择器。多行 OCR 默认全选，用户可在翻译前剔除页码和页眉。

  • 1识别完成后不直接翻译全部，给用户一次轻量确认。
  • 2卡片跟随选区出现，保留空间归属感。
  • 3复制与翻译并列，满足 OCR 文本提取场景。
