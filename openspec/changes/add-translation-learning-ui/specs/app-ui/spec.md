# Spec: App UI 增量 — 翻译学习闭环

## 新增能力

Parrot 的翻译结果界面必须支持把陌生词/高价值表达沉淀为可复习的个人学习对象，并在不破坏“即用即走”翻译体验的前提下提供语境解释、微练习、复习和词库画像。

## Requirements

### 结果面板

- MUST 在译文中高亮系统推荐的高价值词/短语。
- MUST 默认限制推荐数量，首版默认每句最多 3 个。
- MUST 在译文卡底部显示 LearningStrip，包含建议表达数量和 chip。
- MUST 在高亮词或 LearningStrip chip 上展示该表达在用户历史翻译中的出现次数。
- MUST 支持点击高亮或 chip 打开语境词义弹层。
- MUST 支持没有推荐时完全隐藏学习层。

### 语境词义弹层

- MUST 展示当前句中含义，而不是只展示词典释义。
- MUST 展示原句词块和常见搭配。
- MUST 支持“认识”“加入词库”“已掌握”三类反馈。
- SHOULD 展示掌握阶段。
- SHOULD 展示历史出现次数，并与词库列表中的计数一致。

### 微练习

- MUST 使用用户当前翻译句子生成挖空练习。
- MUST 在答题后展示答对/答错反馈。
- SHOULD 将答题结果写入后续复习队列。

### 每日复习

- MUST 以独立窗口展示今日复习队列。
- MUST 复用用户历史翻译句子作为复习上下文。
- SHOULD 支持原句挖空、迁移句、主动回忆三种卡片类型。

### 个人词库画像

- MUST 支持搜索和状态筛选。
- MUST 展示词/短语、来源场景、掌握阶段、历史出现次数和下次复习时间。
- SHOULD 展示已掌握数量、待复习数量、反复遗忘数量和查词下降估计。

### 设置

- MUST 在设置窗口新增学习分区。
- MUST 支持开关自动识别陌生词。
- MUST 支持设置每句推荐上限。
- MUST 支持设置复习强度和目标水平。

## Acceptance Criteria

- [ ] HTML 原型覆盖结果面板、词义弹层、微练习、每日复习、词库画像、学习设置。
- [ ] HTML 原型支持浅色/深色切换。
- [ ] 用户可以点击不同词条并看到语境解释切换。
- [ ] 翻译结果、学习条和词库列表可以看到历史出现次数。
- [ ] 用户可以完成一次微练习并看到反馈状态。
- [ ] 用户可以在复习窗口切换卡片并选择答案。
