# Review: 翻译学习闭环 UI

## Code Review

- ResultPanel 已接入学习层：英文译文或英文源句会生成高价值表达推荐；没有候选表达时保持原有纯翻译卡片。
- 英译中场景会保留中文译文，并在同一卡片中补充英文源句高亮，避免推荐来自源句但用户看不到位置。
- 历史出现次数来自本地 `HistoryStore` 的真实记录统计，不使用静态 mock 数据。
- 学习设置写入 `UserDefaults`，包括自动识别、微练习、推荐上限、复习强度、目标水平、真实句子开关和词条反馈状态。
- 验证：`swift build` 通过；`swift test` 86 项通过；`git diff --check` 通过。

## Architecture Review

- 新增 `LearningSupport.swift` 承载推荐、频次统计、共享视觉组件；`LearningWindows.swift` 承载每日复习与个人词库窗口。
- `AppState` 只发布历史记录与频次索引，不把学习推荐逻辑塞进翻译管线，避免影响 provider 聚合。
- 当前实现覆盖基础复习队列、掌握阶段推断和“加入词库/已掌握”反馈持久化；正式间隔复习算法仍保留为后续项。

## UI Review

- 结果面板还原 HTML 视觉稿的学习识别 chip、高亮词、频次徽标、LearningStrip、语境卡和 10 秒微练习。
- 词条切换时微练习会重置答题状态，避免上一题反馈残留到新词条。
- 新增 `今日复习` 与 `个人词库` 两个原生 macOS 窗口，沿用现有实色卡片、侧栏、0.5px 描边和 `#6D85C9` 强调色。
- 设置页新增 `学习` 分区，布局与现有设置窗口一致，没有引入独立营销页或背词首屏。

## Residual Risk

- SwiftUI 实现已通过编译和测试，但尚未做人工逐像素 GUI 截图评审。
- 学习词库当前由历史记录动态生成；尚未落独立词库数据模型、复习日期、错误次数和完整间隔复习调度。
